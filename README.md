# B-JOB FBS

Специализированная web-система для работы с FBS-складом.

## Первый этап
- каркас SPA;
- локальная авторизация без сервера;
- роли: администратор, менеджер, сборщик;
- локальная база через `localStorage`;
- навигация по рабочим разделам;
- мастер создания склада;
- базовая схема склада, рабочие пространства, зоны и короба;
- автоматический просмотр учета склада;
- GitHub Pages deployment.

### Демо-доступ администратора
`Admin` / `Admin123`

> Важно: авторизация без сервера предназначена для прототипа. Пароли хранятся в браузере и не являются защищенным production-хранилищем.
